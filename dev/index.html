PhyloMakie.jl

PhyloMakie is a Makie-native plotting package for phylogenetic trees and networks stored as PhyloNetworks.HybridNetwork values.

PhyloMakie registers a Makie recipe for HybridNetwork, so the standard Makie entry points work directly:

plot(net)
plot!(axis, net)

The package also exports phyloplot and phyloplot! as package-specific aliases for the same plotting behavior.
