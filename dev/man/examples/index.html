Example scripts

The repository's examples directory contains complete Julia scripts for the topics covered in the manual. Follow Getting started for an introduction to the phylogeny types and Makie objects, then choose a script below to explore or adapt.

Run a script

Clone or download the PhyloMakie repository, then open a terminal in its root directory. Instantiate the examples environment once:

julia --project=examples -e 'using Pkg; Pkg.instantiate()'

This environment uses the local PhyloMakie checkout and installs the example dependencies, including PhyloPicMakie for the optional PhyloPic examples. Package installation requires internet access.

Start Julia in that environment:

julia --project=examples

For example, run the node and edge image script, which uses image files included in the repository:

figure = include("examples/src/07_node_edge_images.jl")
display(figure)
save("node_edge_images.png", figure)

That script loads CairoMakie, which supplies save. CairoMakie scripts can render files without a desktop display. GLMakie scripts open interactive windows and need a graphical display with OpenGL support. Run a walkthrough one section at a time in the Julia REPL or editor to see intermediate figures and updates; include executes the entire file and returns its last value.

Command-line viewer

05interactiveex1.jl launches the interactive viewer described in the Command-line app guide. Run it as a separate process, with a path to a Newick or NEXUS file:

julia --project=examples examples/src/05_interactive_ex1.jl /path/to/tree.newick

This script calls exit when the viewer finishes, so run it from a terminal instead of including it in a working REPL session. It requires a graphical display.
